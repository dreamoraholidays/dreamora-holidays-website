# Dreamora Holidays Website — Version 1

This is the first professional website draft for Dreamora Holidays.

## Included
- Responsive premium design
- Dreamora Holidays transparent logo
- WhatsApp enquiry buttons
- Call button
- Instagram + Facebook links
- Thailand package section
- Upcoming group tour section
- Gallery
- Why Choose Us
- Reviews placeholders
- FAQ
- Mobile menu
- SEO-ready title and description

## Important before publishing
1. Replace the temporary gallery/hero visuals with your own tour photos.
2. Replace the three sample review texts with real verified customer reviews.
3. Confirm the latest package price and inclusions before publishing.
4. Add Google Maps only after you have the office/location link.
5. Add Privacy Policy and Terms & Conditions before collecting form data.

## Easy editing
- Main content: `index.html`
- Design/colors/layout: `styles.css`
- WhatsApp number and WhatsApp message: `script.js`
- Logo: `assets/dreamora-logo.png`

The site is intentionally built without a paid theme or page builder so it can be hosted on a free static hosting service and customized later.
